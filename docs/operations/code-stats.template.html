Jak se počítalo

  • Aktuální lokální soubory sledované Gitem a nové soubory, které nejsou ignorované. Nejde o celou historii repozitáře.
  • Počítají se zdrojové přípony: %%EXTENSIONS%%. Zahrnuty jsou také HTML prototypy, konfigurace v těchto jazycích, migrace a testovací data v SQL.
  • Vynechány jsou závislosti, buildy, cache, reporty, minifikované JS/CSS, obrázky, Markdown, JSON, YAML, lock soubory a tento přehled s jeho šablonou.
  • Testy jsou určeny podle adresářů tests/test/e2e/__tests__, názvů test_*, *.test.*, *.spec.* a conftest.py. Ostatní soubory se dělí podle složek backend a frontend.
  • Znaky jsou Unicode znaky včetně mezer a původních konců řádků; případný UTF-8 BOM se nepočítá. Neprázdné řádky vylučují i řádky tvořené pouze mezerami.

Pro aktuální čísla otevři dvojklikem otevrit-prehled.bat v této složce. Spouštěč nejprve přepočítá soubory a pak otevře tento přehled. Samotný HTML soubor ani jeho obnovení v prohlížeči nové měření nespustí. Funguje offline; potřebuje Python a Git.
